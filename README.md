# LifeStyle_Android

LifeStyle_Android is a comprehensive daily companion application designed to help users manage their daily routines, track health metrics, and access quick utility tools.

## Features

### 1. Daily Dashboard
- **Personalized Greetings**: Dynamic greetings based on the time of day (Morning, Afternoon, Evening, Night).
- **Date Display**: Shows the current day and date.

### 2. Productivity Tools
- **Quick Notes**: A dedicated section for jotting down thoughts, reminders, or plans for the day.
- **Daily Checklist**: An interactive to-do list where users can add, mark as complete, or delete tasks.

### 3. Health & Wellness
- **Hydration Tracker**: Monitor your daily water intake with a goal-oriented tracker (8 glasses a day) featuring a circular progress indicator.
- **BMI Calculator**: Quickly calculate your Body Mass Index by entering weight and height to understand your health status.

### 4. Utility Tools
- **Age Calculator**: Determine your age instantly by entering your birth year.
- **Quick Calculator**: A handy tool for performing basic arithmetic operations on the go.

## Technical Highlights
- **Jetpack Compose**: Built with a modern declarative UI framework for a smooth and responsive user experience.
- **MVVM Architecture**: Follows the Model-View-ViewModel pattern for clean code separation and maintainability.
- **Data Persistence**: Uses local storage to ensure your notes, checklist, and hydration data are saved across sessions.
- **Material 3 Design**: Features a clean, modern aesthetic with custom themes and animated transitions.

## Project Structure
- `ui`: Contains the Compose screens, ViewModels, and UI components.
- `model`: Defines the data structures used in the app.
- `data`: Handles local data persistence and repository logic.
